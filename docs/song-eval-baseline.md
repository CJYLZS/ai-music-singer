## 参考素材（全部歌曲共用）

- 参考：`data/voices/ref_talk_sing.wav`（说话+唱歌混合素材，537.8s，kNN 池也用它）

- SingMOS：`tools/singmos/score_naturalness.py`，原唱=`sep2/lead.wav` 作对照锚点

## 基线参数说明（重要）

- **13/14 首歌的 `vocal.wav` 是用旧默认流程合成的**：整曲单 prompt（`--svc-prompt ext`，
  全曲 `prompt_ext.wav` 约 45s）、`--seed 1`、CFM `n_steps 32 / cfg 0.5 / rescale_cfg 0.75`、
  `max_seg_sec 28`、`num_overlaps 1`。其中 kNN 强度按批次不同：8/16 批次 α=0.0（无 kNN），
  个别歌（情歌、爱笑的眼睛 8/22 重跑）α=0.2 + 全参考 kNN 池。
- **亲亲是唯一已用 segprompt 的**：`--svc-prompt segprompt`（11 段，seed 1234，kNN α=0.2，
  全参考池），`vocal.wav` 与 `vocal_segprompt2.wav` 同内容（md5 `6f88986f5d...`）。
- 因此这次全量重跑后，13 首歌会从「ext 整曲单 prompt / seed 1 / (无或 0.2) kNN」切换到
  「segprompt 分段 / seed 1234 / kNN 0.2」，亲亲理论上应复现（同参数）。

## 重跑计划（另见后续更新）

1. 清理各歌曲目录中可再生的 SVC/评测产物（svc/、segprompt_tmp*/、eval.txt、natmos_*、
   leak_report.json、旧 vocal 变体等；保留 sep1/sep2/sep4、target_f0.npy、cands/、
   cands_meta.json、prompt*.wav/f0、asr_*、参考类产物）。
2. 全部 14 首歌用最新默认参数重跑：
   `sing.py --ref data/voices/ref_talk_sing.wav --song data/songs/<歌>.flac --name <歌> \
   --stages svc,eval --seed 1234`
   （segprompt 为默认 svc 模式；--seed 1234 固定 CFM 噪声种子，全曲可复现）。
3. 对比本文件基线，记录变化。
